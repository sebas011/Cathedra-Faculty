CATHEDRA FACULTY - INSTALL OR UPDATE

1. Save your work in Cathedra, then choose Exit Cathedra.
2. Download Cathedra-Faculty-Setup.exe:
   https://github.com/sebas011/Cathedra-Faculty/releases/latest/download/Cathedra-Faculty-Setup.exe
3. Open the downloaded file and choose Update Cathedra.
   On a new computer, choose Install Cathedra instead.

Setup checks and extracts the package for you. For an update, it creates and
verifies a private recovery copy before replacing application files. Your
existing records, accounts and settings stay in the data folder. Keep setup
open until it says Cathedra is ready; a large office may take a few minutes.
Cathedra opens automatically. Later, use the Cathedra Faculty desktop shortcut.

Use your usual Windows account. ZIP extraction, administrator rights, Python
and Node.js are not required.

IF CATHEDRA IS STILL OPEN
Save any open work and choose Exit Cathedra in every Cathedra window. Return
to setup and choose Try again. Setup does not force-close your open work.

UPDATING AN ORIGINAL 0.3.2 COPY
The corrected installer recognizes seven known extra files from the original
0.3.2 installation. They are included in the private recovery copy and kept
separate from the new app. You do not need to move or delete these files.
If another verification error appears, keep the installation and records in
place and share the setup message with your office support person.

RECOVERY
Keep the private recovery folder shown by setup. If application replacement
fails, the installer attempts to restore and verify the previous app. If it
reports a recovery problem, keep all named folders and request support before
opening Cathedra. Returning to an older version requires the matching old app
and old database together; preserve any newer office work separately first.

INSTALLING ON A DIFFERENT COMPUTER
A new installation starts empty. Transfer existing records privately through
Cathedra's Backup & Export page. Computers do not synchronize automatically.
Keep databases, account details, Google keys and recovery copies private.

OPTIONAL ZIP DOWNLOAD
The Windows ZIP remains available on the GitHub release page. If you choose
it, extract all files together and run Install-or-Update.cmd from that folder.
For normal office updates, use Cathedra-Faculty-Setup.exe above.

Setup is currently unsigned, so Windows may display a publisher warning.
